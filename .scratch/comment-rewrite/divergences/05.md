A line number in `src/` refers to the code at commit `fb437d0d`, the commit before this ticket.

## D05-1 — Six stages have no output file, and the old comments count four

- **Where:** `src/pipeline/layout.ts:247` (`StageFiles.outputFile`), `src/pipeline/layout.ts:515` (`StageWithOutputFile`) and `src/pipeline/layout.test.ts:220`, found in ticket 05.
- **The code does:** `STAGE_FILES` (`src/pipeline/layout.ts:454–505`) gives `outputFile: null` to six stages: `source-normalisation`, `initial-subtopic-splitting`, `deepen-subtopic-splitting`, `image-extraction`, `qa-loop` and `pdf-generation`. The reasons are three: no file of its own, a set of files, and a file outside the workspace.
- **The intent says:** the old comment on `outputFile`: "The four `null`s are four separate facts rather than one". The old comment on `StageWithOutputFile`: "The four stages left out are left out for four different reasons (§3.3)". The old test comment: "The four stages that write no single file cannot be asked for one at all".
- **Other sources:** technical-design.md §3.3 (`STAGE_FILES`, line 294) agrees with the code. It names all six stages and gives no count.
- **Status:** open

## D05-5 — The loader accepts a stage entry that holds only a model ID

- **Where:** `src/pipeline/config.integration.test.ts:123` (`structuringStage`), found in ticket 05.
- **The code does:** `requireStageConfig` (`src/pipeline/config.ts:401–417`) reads only `modelId` as required: `modelId: stage.string("modelId")`. It reads every other field as optional: `temperature`, `maxTokens`, `concurrency` and `maxIterations` with `stage.optionalNumber(...)`, and `callConcurrency` and `sendGapSeconds` with `requireSingleStageSetting(...)`, which returns `undefined` when the setting is unset. So the loader accepts a bare `{ modelId }` entry.
- **The intent says:** the old comment on `structuringStage`: "The tests that reach for it change one field and leave the rest of the example's tuning standing — replacing the whole entry would drop that tuning and fail the loader for a reason the test is not about."
- **Other sources:** none found.
- **Status:** open
