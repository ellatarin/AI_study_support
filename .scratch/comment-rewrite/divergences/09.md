# Divergences found in ticket 09

A line number in `src/` refers to the code at commit `52bd0c0a`, the commit before this ticket.

## D09-1 — An unreadable deepened splitting run does not raise `ChooseDivisionError`

- **Where:** `src/pipeline/stages/choose-division/choose-division.ts:20` (`ChooseDivisionError`), found in ticket 09.
- **The code does:** `readInput` calls `readTranscriptAndRuns` (`src/pipeline/stages/stage-input.ts:149–164`). A missing run raises the error that `fail` builds, so `ChooseDivisionError`. A saved run that is there but holds no readable run raises `SavedRunUnreadableError` (`src/pipeline/stages/panel-runs.ts`, `readSavedRun`), not `ChooseDivisionError`.
- **The intent says:** the old comment: "The stage could not choose a division: its transcript or a deepened run is missing or unreadable."
- **Other sources:** technical-design.md §5, "Dividing the transcript", Panel runs, agrees with the code: "A saved run file that cannot be read is a named error rather than a run to remake". The TSDoc of `readTranscriptAndRuns` agrees with the code.
- **Status:** open

## D09-2 — The technical design names the config section `division`, and the code reads `subtopicSplitting`

- **Where:** technical-design.md §5, "Dividing the transcript", Configuration (line 1125), found in ticket 09.
- **The code does:** `splittingPanel` (`src/pipeline/stages/division.ts:146`) reads `context.config.subtopicSplitting.panelSize`. `deepenSubtopic` reads `subtopicSplitting.sizeGateWords`, and `choose-division` reads `subtopicSplitting.bar`.

- **Other sources:** ticket 02, rulings B7 and S15, agree with the code: the section `division` becomes `subtopicSplitting`. The comment on `splittingPanel` (`division.ts:139`) still says "whose `division` section sizes the panel".
- **Status:** open

## D09-3 — The old comments count three division stages, and the glossary counts four

- **Where:** `src/pipeline/stages/initial-subtopic-splitting/initial-subtopic-splitting.ts:2` and `src/pipeline/stages/deepen-subtopic-splitting/deepen-subtopic-splitting.ts:2`, found in ticket 09.
- **The code does:** not applicable. This is a disagreement between two statements of intent.
- **The intent says:** the old comments: "the first of the three division stages" and "the second of the three division stages". The header of `src/pipeline/stages/division.ts` says "shared by the three division stages".
- **Other sources:** `CONTEXT.md`, Division stages, counts four.
