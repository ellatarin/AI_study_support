# Grouping prompt versions and what they scored

Generated by `report-grouping.py` — do not edit by hand. Structure comes from
the run files; the five criteria are hand judgements in `runs/criteria.json`.

Every table below is **one lecture**. None of these numbers travel between
transcripts — a topic count, a singleton rate and the five criteria all describe
one lecture's material — so runs are never pooled across lectures.

**Pass 1** names the splitting prompt version from `split-prompts.mts` that cut
the subtopics; **pass 2** groups them in a separate call. **Labels** is whether
pass 1's subtopic labels were sent up with the text; they are restored either
way, so it changes what the grouping model sees, not what the reader gets. Both
passes run on `google/gemini-3.7-flash`.

The five criteria are lecture 4's rubric, taken from the user's critique of run
h4. A lecture with no rubric of its own scores `—`, which means unjudged, not
failed.

## What each version is

### g1 — The kind rule stated for topics, plus a re-read pass that asks only whether to divide.

*Changed:* First version.

- **l4, pass 1 s1, labels shown**: 6 of 6 runs met all five; 12–15 topics, 56/79 single-subtopic, 0 collapsed; 29–63s, $0.029 a run.

### g2 — The kind rule removed; the re-read pass kept, reworded to ask whether the topic is one thing.

*Changed:* Dropped THINGS THAT DIFFER IN KIND. The re-read paragraph could no longer reference it, so it now asks whether the topic is really one thing.

- **l4, pass 1 s1, labels withheld**: 4 of 6 runs met all five; 5–7 topics, 9/36 single-subtopic, 1 collapsed; 14–39s, $0.019 a run.
- **l4, pass 1 s1, labels shown**: 4 of 6 runs met all five; 4–7 topics, 7/34 single-subtopic, 1 collapsed; 15–42s, $0.019 a run.

### g3 — The kind rule and the re-read pass both removed.

*Changed:* Dropped THEN READ IT AGAIN entirely. It only ever asked whether to divide a topic, never whether to join two, so it could push the topic count in one direction only.

- **l4, pass 1 s1, labels withheld**: 9 of 17 runs met all five; 4–6 topics, 18/88 single-subtopic, 7 collapsed; 13–23s, $0.018 a run.
- **l4, pass 1 s1, labels shown**: 3 of 6 runs met all five; 4–6 topics, 7/32 single-subtopic, 3 collapsed; 9–22s, $0.016 a run.

### g4 — g3 plus an instruction to analyse for the optimum arrangement, and a groupedBecause test that compares splitting against keeping.

*Changed:* Added ANALYSE, which asks for the optimum arrangement rather than a walk through the subtopics in order. Replaced the honest-justification test with a comparative one: split when the groupedBecause sentences would be better for it. The first version to weigh an alternative arrangement rather than judge the one in hand.

- **l4, pass 1 s1, labels withheld**: 9 of 16 runs met all five; 5–7 topics, 20/93 single-subtopic, 1 collapsed; 12–60s, $0.018 a run.

### g5 — g4 plus a rule that a groupedBecause built as a list of kinds is not one topic.

*Changed:* Added NO_ENUMERATION to g4's justification paragraph. Derived from g4's own runs: all six that merged two topics justified the merge by listing kinds, while all ten that kept them apart named a single kind or mechanism. Stated with none of the lecture's nouns, so it does not teach this transcript.

- **l4, pass 1 s1, labels withheld**: 1 of 2 runs met all five; 4–6 topics, 2/10 single-subtopic, 1 collapsed; 18–24s, $0.020 a run.

### g6 — g5's rules restated as a structured document — markdown headings, named rules R1 to R6, and a checklist.

*Changed:* Presentation only. Every rule of g5 is carried over unchanged in substance; they are now named and numbered so the model can check its answer against them by name. Tests whether a rule that can be pointed at binds better than the same rule in prose — g5's added rule described its own violation without preventing it.

- **l4, pass 1 s1, labels withheld**: 14 of 16 runs met all five; 5–7 topics, 22/101 single-subtopic, 1 collapsed; 17–43s, $0.021 a run.
- **l5, pass 1 s1, labels withheld**: unjudged; 5–7 topics, 7/19 single-subtopic, 0 collapsed; 14–25s, $0.018 a run.
- **l5, pass 1 s3, labels withheld**: unjudged; 5–6 topics, 8/32 single-subtopic, 0 collapsed; 15–35s, $0.020 a run.

### g7 — g6 with R4 reworded: state the rationale for every proposed topic, rather than every topic carrying one.

*Changed:* R4 only. The rule becomes an instruction to perform rather than a property to satisfy, and names the topic as PROPOSED — asking for the rationale while the grouping is still open. Everything else is g6 byte for byte.
